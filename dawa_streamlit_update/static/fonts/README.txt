Put the Thmanyah (ثمانية) font files here, e.g. thmanyah-sans-regular.otf, thmanyah-sans-bold.otf

Download them yourself from the official page (you receive them by email):
https://ask.thmanyah.com/hc/en-001/articles/45993930027281-Thmanyah-Font-for-Everyone

The font license does NOT allow uploading or hosting the files for download, so they must
not be committed to GitHub. The .gitignore in this folder already keeps them out of git.
The app picks the weight from the file name (regular, medium, bold, ...). If a file name has
no weight word, it is treated as regular (400).
